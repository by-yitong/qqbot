# 目标
QQ 官方 bot 的 markdown（MsgType=2）里正确发代码，不糊格式。

# 背景（2026-09 本群实测敲定的最终规则）
- QQ 客户端支持代码块渲染，且**必须标注语言**（```go）才触发识别——裸 ``` 围栏不渲染。
- **回复开头不能直接是 ```**：markdown 消息以三反引号开头时 QQ 识别不到代码块。开头先放一行文字，或加一个换行，再接代码块。

# 正确写法（缺一不可）
1. 消息开头必须是文字（哪怕一行短说明）或换行，**不能直接以 ``` 起头**。
2. 围栏开头必须标语言：```go / ```python / ```json，独占一行。
3. 围栏前后与正文空行隔开；代码内容独立成行；结尾三反引号独占一行。
4. 缩进用 4 空格，**禁全角空格**。
5. 不嵌套三反引号；代码行内避免行首 # * _ > 等 markdown 元字符。
6. 单行别超长（QQ 代码块不自动换行，一行 ~30 全角字符内）。

# 发代码模板
给你一个精简版：

```go
func A() string {
    return "hi"
}
```

说明/要点跟在后面。

# 兜底
超长代码（>40 行）或含特殊符号发不稳时：写文件传 pastebin 换短链，或让用户去仓库看。
